# PRD: 감정 브레이크 AI 에이전트

## 1. 제품 목적

감정 브레이크 AI 에이전트는 사용자가 감정적으로 격해진 순간에 바로 사용할 수 있는 웹 서비스다.

사용자가 텍스트 또는 음성으로 상황을 털어놓으면, 서비스는 감정 강도를 확인하고 필요한 경우 60초 진정 루틴을 먼저 제공한다. 이후 사용자의 말을 사실, 해석, 감정, 욕구로 분리하고, 상대에게 보낼 말을 차분한 표현으로 바꿔준다.

## 2. 문제 정의

감정이 올라온 순간 사용자는 즉각적인 답장, 따짐, 공격적 표현, 회피 같은 충동적 행동을 하기 쉽다. 기존 상담 서비스나 명상 앱은 사용자가 바로 폭발 직전일 때 쓰기에는 무겁거나 느릴 수 있다.

이 제품은 그 짧은 순간에 개입해 "멈춤, 진정, 정리, 표현"을 빠르게 돕는다.

## 3. 대상 사용자

- 화가 나서 바로 답장하고 싶은 사람
- 불안이나 억울함 때문에 생각이 꼬인 사람
- 상대에게 할 말을 차분히 정리하고 싶은 사람
- 감정을 저장하고 나중에 돌아보고 싶은 사람
- 상담이 아니라 즉시 쓸 수 있는 감정 조절 도구가 필요한 사람

## 4. MVP 필수 기능

| 기능 | 설명 |
| --- | --- |
| 홈 화면 | 서비스 진입 및 입력 방식 선택 |
| 텍스트 입력 | 상황과 보내고 싶은 말을 자유롭게 입력 |
| 음성 입력 | MVP 후반에 STT로 확장 |
| 감정 강도 선택 | 0~10점 감정 온도계 |
| 점수 기반 분기 | 0~3, 4~6, 7~10 기준 분기 |
| 60초 브레이크 | 고강도 감정에서 진정 루틴 제공 |
| 재평가 | 루틴 후 감정 점수 재입력 |
| AI 분석 | 감정, 사실, 해석, 욕구 분리 |
| 문장 추천 | 부드럽게, 단호하게, 짧게 기본 제공 |
| 도움 자료 추천 | 사용자가 요청한 경우에만 제공 |
| 세션 저장 | 명시적 저장 선택 시 DB 저장 |
| 세션 삭제 | 민감 기록 삭제 가능 |
| 위험 대응 | 자해/타해/즉각 위험 표현 대응 |

## 5. 비즈니스 룰

### 감정 점수 분기

| 점수 | 분기 |
| --- | --- |
| 0~3 | 생각 정리 모드로 바로 이동 |
| 4~6 | 짧은 안정 루틴 후 생각 정리 |
| 7~10 | 60초 감정 브레이크 모드 우선 실행 |

### 도움 자료 추천 룰

- 자동 추천하지 않는다.
- 사용자가 자료 유형 버튼을 누른 경우에만 추천한다.
- 초기 MVP는 사전 큐레이션 DB만 사용한다.
- 외부 YouTube/도서 검색 API는 추후 확장한다.

### 저장 룰

- 자동 저장하지 않는다.
- 사용자가 `저장하기`를 누른 경우에만 저장한다.
- 비회원은 `anonymous_id` 기반으로 저장할 수 있다.
- 로그인 적용 후에는 `user_id`와 연결한다.

### 위험 표현 룰

위험 표현이 감지되면 일반 감정 분석, 문장 추천, 도움 자료 추천 흐름을 중단한다.

안내 문구:

```text
지금은 혼자 버티기보다 즉시 도움을 받는 게 중요해 보여요.
가까운 사람에게 바로 연락하거나, 긴급 상황이라면 112 또는 119에 연락해 주세요.
```

## 6. 주요 화면

1. 홈
2. 감정 빠른 선택
3. 텍스트 입력
4. 음성 입력
5. 감정 강도 선택
6. 60초 감정 브레이크
7. 감정 재평가
8. 분석 결과
9. 문장 추천
10. 도움 자료 추천
11. 기록 목록
12. 기록 상세

## 7. 성공 기준

- 사용자가 텍스트로 상황을 입력할 수 있다.
- 사용자가 감정 강도를 선택할 수 있다.
- 감정 강도 7점 이상이면 60초 루틴이 실행된다.
- 루틴 후 감정 점수를 다시 입력할 수 있다.
- AI가 사실 / 해석 / 감정 / 욕구를 분리한다.
- AI가 상대에게 보낼 문장을 최소 3가지 톤으로 추천한다.
- 사용자가 요청한 경우에만 도움 자료를 추천한다.
- 감정 세션을 저장하고 삭제할 수 있다.
- 위험 표현이 감지되면 일반 코칭 대신 위기 안내로 전환된다.
- API 키가 프론트엔드에 노출되지 않는다.

## 8. 제외 범위

- 정신질환 진단
- 치료 또는 의료 조언

- 실시간 YouTube 검색
- 실시간 도서 검색
- 커뮤니티 기능
- 관리자 CMS
