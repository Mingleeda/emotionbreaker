# Design Guide

## 디자인 방향

보내기 전 60초는 화나고 흥분한 상태에서 사용하는 감정 브레이크 도구다. 따라서 디자인의 목표는 아름다운 장식보다 빠른 이해, 큰 조작, 즉시 멈춤이다.

핵심 방향:

- 직관적이고 큰 선택지
- 짧고 단호한 문장
- 한 화면에 하나의 주요 행동
- 감정이 높은 상태에서는 분석보다 멈춤을 먼저 강조
- 도움 자료와 저장은 사용자가 명시적으로 선택할 때만 노출

## 톤

- 훈계하지 않는다.
- 진단처럼 말하지 않는다.
- 사용자의 감정을 인정하되, 행동은 늦춘다.
- "바로 답장 금지", "60초만 멈춰요"처럼 즉시 이해되는 문장을 쓴다.

## 컬러

팔레트는 피치 + 세이지 + 차콜을 기준으로 한다. 화면 전체를 베이지나 단색 계열로 밀지 않고, 따뜻한 배경 위에 차콜 CTA와 피치 포인트를 적게 쓴다.

| 역할 | 색상 방향 | 사용처 |
| --- | --- | --- |
| Background | warm off-white `#FBF8F4` | 전체 배경 |
| Primary | sage charcoal `#25342D` | 주요 CTA, 핵심 텍스트, 앱 테마 |
| Body Text | muted sage `#46564E` | 본문, 보조 안내 |
| Accent | peach `#C56F5C` | 단계 표시, 아이콘, 포커스 |
| Calm Surface | soft sage `#EEF4EB` | 안정 안내, 보조 배지 |
| Risk | soft peach/red | 위기 안내, 높은 감정 점수 |
| Surface | white | 입력창, 결과 블록, 선택 버튼 |

## 타이포그래피

- 제목은 굵고 크게 쓴다.
- 본문은 18px 이상을 기본으로 둔다.
- 버튼은 20px 전후의 굵은 글자로 만든다.
- 좁은 모바일 화면에서도 문장이 버튼 안에서 잘리지 않게 한다.

## UI 규칙

1. 주요 버튼 높이는 최소 64px로 둔다.
2. 감정 점수 버튼은 숫자를 크게 보여준다.
3. 하단 고정 CTA는 입력/브레이크/분석처럼 다음 행동이 명확한 화면에만 쓴다.
4. 반복 정보는 흰색 surface 블록으로 나눈다.
5. 중첩 카드 구조는 피한다.
6. 아이콘은 lucide-react를 사용한다.
7. 위험 안내는 일반 분석 UI와 분리한다.

## 핵심 화면 의도

### Home

첫 화면은 서비스명과 행동을 함께 담은 "보내기 전에 60초만 멈춰요"를 가장 크게 보여준다. 사용자는 즉시 말하기 또는 글쓰기를 선택할 수 있어야 한다.

### Input

사용자가 정리되지 않은 말을 적을 수 있도록 큰 textarea를 제공한다. 다음 행동은 하단 고정 버튼 하나로 제한한다.

### Intensity

0~10 숫자를 크게 보여준다. 7점 이상은 피치 위험 톤으로만 강조하고, 나머지는 흰색 surface와 차콜/세이지 텍스트로 차분하게 유지한다.

### Break

타이머가 가장 먼저 보인다. 사용자는 "60초 시작"과 "다 했어요"만 크게 볼 수 있다.

### Analysis

분석 결과보다 "먼저 할 일"을 가장 먼저 보여준다. 사실, 해석, 욕구는 별도 블록으로 나눈다.

### Rewrite

추천 문장은 톤별로 크게 보여주고, 복사 버튼을 명확히 제공한다.

### Resources

도움 자료는 자동 노출하지 않는다. 사용자가 자료 유형을 직접 선택한 뒤에만 추천을 보여준다.
