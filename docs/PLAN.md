# Development Plan

## Phase 0. 문서와 프로젝트 기준 정리

- `CLAUDE.md` 작성
- `docs/PRD.md` 작성
- `docs/USER_STORIES.md` 작성
- `docs/DATA_MODEL.md` 작성
- `docs/PLAN.md` 작성
- `apps/web/CLAUDE.md` 작성

완료 기준:

- 제품 목적, 요구사항, 데이터 모델, 개발 순서가 문서화되어 있다.

## Phase 1. 프로젝트 세팅

- Next.js 프로젝트 생성
- TypeScript 적용
- Tailwind CSS 적용
- ESLint 및 기본 포맷팅 설정
- `.env.local.example` 작성
- 기본 App Router 구조 생성

완료 기준:

- 로컬 개발 서버 실행 가능
- `/` 기본 페이지 접근 가능
- Tailwind 스타일 적용 확인

## Phase 2. 기본 UI 플로우

- 홈 화면
- 감정 빠른 선택
- 텍스트 입력
- 감정 온도계
- 60초 브레이크
- 감정 재평가
- 분석 결과 목업
- 문장 추천 목업
- 도움 자료 요청 화면

완료 기준:

- AI와 DB 없이 전체 화면 플로우 이동 가능
- 감정 점수 7점 이상이면 브레이크 화면으로 이동
- 도움 자료는 요청 시에만 표시

## Phase 3. 플로우 상태 관리

- `EmotionFlowState` 타입 정의
- localStorage 기반 임시 저장소 구현
- 화면 간 데이터 유지
- 플로우 초기화 기능 구현

완료 기준:

- 새로고침 후에도 입력값과 점수가 복원된다.
- 완료 후 플로우를 초기화할 수 있다.

## Phase 4. AI 감정 분석

- OpenAI 클라이언트 구성
- 분석 프롬프트 작성
- JSON 응답 스키마 정의
- `/api/analyze-emotion` 구현
- 위험 표현 로컬 1차 감지
- 위기 안내 UI 연결

완료 기준:

- AI가 감정, 사실, 해석, 욕구를 분리한다.
- 위험 표현 입력 시 일반 코칭이 중단된다.

## Phase 5. 문장 변환

- `/api/rewrite-message` 구현
- 기본 3가지 톤 제공
- 추가 톤 요청 기능
- 클립보드 복사 기능

완료 기준:

- 상대에게 보낼 문장을 부드럽게, 단호하게, 짧게 변환한다.
- 사용자가 추천 문장을 복사할 수 있다.

## Phase 6. Supabase 저장/삭제

- Supabase 클라이언트 구성
- DB migration 작성
- 세션 저장
- 추천 문장 저장
- 기록 목록 조회
- 기록 상세 조회
- 기록 삭제

완료 기준:

- 사용자가 명시적으로 저장한 세션만 DB에 저장된다.
- 저장된 기록을 조회하고 삭제할 수 있다.

## Phase 7. 도움 자료 추천

- 큐레이션 seed 데이터 작성
- `/api/resources` 구현
- 감정/상황/유형 기반 필터링
- 자료 클릭 및 피드백 로그 저장

완료 기준:

- 사용자가 선택한 자료 유형만 추천된다.
- 추천 자료는 초기 DB 데이터에서만 제공된다.

## Phase 8. STT

- 브라우저 음성 녹음
- 최대 3분 제한
- `/api/transcribe` 구현
- OpenAI STT 연동
- STT 결과 수정 화면

완료 기준:

- 사용자가 음성으로 입력할 수 있다.
- 변환된 텍스트를 수정한 뒤 분석할 수 있다.

## Phase 9. MVP 마감 점검

- 주요 플로우 수동 테스트
- 모바일 화면 점검
- 위험 표현 테스트
- API 키 노출 점검
- 저장/삭제 테스트
- 빈 상태와 오류 상태 보강

완료 기준:

- MVP 완료 기준 10개 항목을 만족한다.
- 로컬에서 전체 플로우가 재현된다.
